# Summarize notes

A short example of a clear brief. Given one or more notes, produce:

1. A 2–3 sentence summary of what happened.
2. A bulleted list of decisions made.
3. A bulleted list of action items, each with an owner if one is named.

## Process
- Read every note you were given before writing anything.
- Prefer the source's own wording for decisions; don't invent specifics.
- If no action items exist, say so explicitly rather than padding the list.

This file is part of a small prompting library: read it for the technique, not as something to
install. The pattern is the same one a good card brief uses: say the outcome first, say what a
finished answer contains, and say what to do when the input is thin. You do not need to write
skills to get work done; state the outcome on a card and the harness handles the rest.
