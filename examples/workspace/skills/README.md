# Example skills — a reading library

These two files are **not** a starter set and you are not expected to add more.
An install gets work done with no skill files at all: each session works out how
to do a card from the card itself, the repo's living docs and the workspace's
knowledge base.

Read them as short examples of prompting technique:

- `draft-update/SKILL.md` — lead with the outcome, bound the length, end with the ask.
- `summarize-notes/SKILL.md` — a fixed, checkable output shape (summary, decisions, actions).

If one of your procedures must be followed exactly, step by step, and no card,
doc or knowledge-base page can hold it, a `skills/<slug>/SKILL.md` is the escape
hatch. See [Skills, Tools & Agents](../../../docs/wiki/Skills-Tools-Agents.md).
